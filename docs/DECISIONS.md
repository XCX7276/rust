## 26.10.2026 — Движок: Rust + Bevy 0.20
- **Почему:** полный контроль над миром и рендером, без магазинов ассетов, ядро на чистом Rust.
- **Варианты:** продолжать только Unity-проект Parodia (уже есть этапы 3–11); Godot (не нравится); Unreal (не хочется Epic).
- **Не решено:** судьба Unity-проекта (параллельно / справочник / ParodiaR как полигон).

## 26.10.2026 — Сборка Windows: MSVC, а не GNU
- **Почему:** набор GNU требовал MinGW (`dlltool.exe`); MSVC — рекомендуемый путь для Bevy.
- **Варианты:** GNU + MSYS2/MinGW.
- **Что поставлено:** Visual Studio Build Tools 2026 (MSVC v143+), пакет Windows SDK, `rustup default stable-x86_64-pc-windows-msvc`.

## 26.10.2026 — Структура: workspace из двух пакетов
- **Почему:** ядро (`parodia_core`) без Bevy — тесты за секунды, обновления Bevy не ломают мир, позже сервер для кооператива на том же ядре.
- **Варианты:** один пакет с модулями (проще на старте, но ничто не мешает ядру зависеть от движка).

## 26.10.2026 — Перенесены решения Parodia (Unity)
- Блок 1 м; мир −3000…+2000; хитбокс-коробка 0,6×1,8×0,6, автоподъём 0,55, прыжок 1,25; камера F5, колесо — зум; формы блоков и мини-части; только `set_block`; сохранение seed + изменения с версией формата; одиночная игра первой.
- **Почему:** приняты и проверены в Unity-проекте, менять без причины не нужно.

## 26.10.2026 — Чанк: вариант А (секции 32³ в столбиках 32 × 256 × 32), мир −3072…+2048
- **Решение:** данные и меш — секция 32³; 8 секций по вертикали = столбик 32 × 256 × 32 — единица подгрузки, сохранения, карты высот и биома. Высота мира −3072…+2048 (20 столбиков), задаётся двумя константами — можно расширить позже.
- **Почему:** Даня хотел 32 × 32 × 256 (так оптимизирует Tantan в Rust + Bevy) и сохранить глубину ~3000. Столбик даёт кэш 2D-шума и биома на 256 блоков и меньше позиций для подгрузки; секции 32³ сохраняют быстрый ремеш при правке блока и бинарный меш на `u32`.
- **Варианты:** мир высотой 256 (теряем глубокие слои); цельный чанк 32 × 256 × 32 (правка блока = ремеш 262 144 блоков). В Unity-проекте остаются кубические чанки 16³.
- **Хранение:** на старте массив + палитра; RLE (как у Tantan) — позже для нетронутых и дальних столбиков.

## 26.10.2026 — Учтённые предупреждения из разборов видео
- В буферах шейдера без `vec3` (выравнивание 16 байт) — Kofybrek.
- Шум Перлина в целых узлах = 0 → координаты всегда с масштабом — Kofybrek.
- Оптимизации мерить на полном мире, в мс (на одном чанке они могут замедлять) — Kofybrek.
- Встроенный PBR Bevy размывает AO → свой упрощённый свет — Tantan.
- RLE медленный при случайном доступе и правках → не для чанков, которые игрок меняет — Tantan.

## 27.10.2026 — Рабочая папка на SSD, один пакет до этапа 2
- **Решение:** игра теперь в `C:\Users\xcx7276\Desktop\rustssd\rust` (SSD). До этапа 2 — один пакет с модулями (`main.rs` + файл на тему), workspace из двух пакетов — на этапе 2.
- **Почему:** нет опыта в Rust и Bevy — сначала освоить модули на одном пакете; SSD быстрее для сборки. Старая папка `D:\Program\rust\ParodiaR` — архив документов.
- **Варианты:** сразу workspace (больше понятий на старте).

## 27.10.2026 — Ускорение сборки
- `rust-lld.exe` как линковщик (`.cargo/config.toml`), папки проекта и `.cargo` в исключениях Защитника, `opt-level` 1 для своего кода и 3 для зависимостей.
- Первая полная сборка Bevy — один раз (10–25 мин на Ryzen 5 4650G); `cargo doc` для всех зависимостей — очень долго (40+ мин), не запускать без нужды: есть `docs/Bevy_RU.pdf`.
