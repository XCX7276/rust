## Мои возможности
- device_bash (Linux-VM на его ПК) видит папку как `$HOME/mnt/rust`; Rust и cargo там НЕТ — компилирует только Даня. В облаке crates.io недоступен → Bevy-код не проверить компилятором; формат проверять `rustfmt --edition 2024`, API сверять с исходниками Bevy v0.20.0 (git clone --branch v0.20.0 с GitHub работает).
- Удалять файлы на его ПК по умолчанию нельзя.

## Правила (подробно — ТЗ разделы 05, 08, 09)
- Одна тема — один файл/плагин. `main.rs` — только сборка.
- Мир меняется только через `set_block`. Блок — не сущность.
- Перед коммитом: `cargo fmt`, `cargo run` (позже + `cargo clippy`, тесты).
- Важные решения — в `docs/DECISIONS.md`.

## Bevy 0.20 — что важно помнить
- Шейдеры — WESL (`.wesl`, `import` без `#`). Сообщения — `Message`/`MessageWriter`/`MessageReader`.
- Встроенный шрифт без кириллицы → `assets/fonts/DejaVuSans.ttf`.
- `KeyCode` — физические клавиши (WASD работает на русской раскладке).
- Не советовать `cargo doc` без нужды (40+ мин на всех зависимостях).
